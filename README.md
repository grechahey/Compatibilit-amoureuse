# Influencer Finder — Beauty DACH

Outil web de **recherche, qualification et suivi d'influenceurs beauté** pour le marché
germanophone (Allemagne · Autriche · Suisse), sur **Instagram** et **TikTok**.

> ⚠️ L'ancien nom de ce dépôt (« Compatibilit-amoureuse ») est hérité d'un projet précédent.
> Le contenu ici est **l'outil de marketing d'influence**, pas un site de compatibilité amoureuse.

## Application en ligne

L'application est le fichier **`index.html`** à la racine (autonome, aucune installation).
Servie publiquement via **GitHub Pages** une fois activé (Settings → Pages → branche `main`, dossier `/`).

## Fonctionnalités

- **Sourcing** de créateurs (4 voies gratuites) + vivier beauté DACH pré-rempli
- **Scoring** de pertinence (pertinence produit, engagement, audience locale, taille, authenticité)
- **Enrichissement de l'engagement** (saisie manuelle / estimation, persistant)
- **Suivi de campagne** (statuts, entonnoir, notes, export CSV)
- **Messages de contact** générés en allemand

Documentation détaillée : dossier `influencer-finder/` sur la branche de développement.
